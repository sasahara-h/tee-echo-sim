### PEC11D について確定したこと（データシート https://www.bourns.com/data/global/pdfs/PEC11D.pdf ）
- **S（ストローク0.5mm）を選んだ理由**：H（1.5mm）だと、ダイヤルを回す指の力で軸が沈み、ゼロ点リセットの誤作動とダイヤルのぐらつきが増える。プッシュは「長押しでゼロ点」にしてファーム側でも誤作動を防ぐ
- **取付金具なし（Hardware: None）、ブッシュ φ7.0 はネジ山なし** → ナット留めはできない。固定は「壁穴にブッシュ」「受け台で回り止め」「小基板を柱にネジ留め」の3点で行う
- 外軸 φ6.0（スリット入り）、ブッシュ φ7.0、本体 12.0角、軸長は取付面から 20.0
- 30クリック/回転、15パルス/回転 → **1クリック＝ダイヤル12°**。4逓倍で数えると60カウント/回転
- 回転トルク 100±70 gf·cm（φ64ダイヤルなら指先で約30gf＝軽い）、軸の横荷重 2.04kgf以上、回転寿命15,000回
- 実物のTEEダイヤルは滑らか、PEC11Dはクリック感あり（試作では許容）

### クリックの刻みの検証（2026-10-15）
- `index.html` に検証用の「クリック刻みモード」を追加済み（コミット d6a2916。「微調整スライダー・表示設定」の一番下）
- 前屈/後屈の刻みを 28 → 14 → 9° と変えて触った結論：**先端の角度で1クリック14°以下でないと練習にならない**
- 前屈/後屈の全範囲は210°（−90〜120）なので、14°以下にするには**15クリック以上＝ダイヤルが止めから止めまで180°以上回る**必要がある
- 判断基準：大学で実物のダイヤルの回転角を測り、**180°以上なら PEC11D で実物どおりの回転角にできる**。180°未満なら、ダイヤルを実物より多く回す設定にする（録画用には十分）か、2号機を磁気センサー（AS5600 など）にする
- 測るもの：大小ダイヤルの止めから止めまでの角度、ダイヤル90°で先端がどれだけ曲がるか、ダイヤル径、オムニプレーンボタンの動き方、ロックレバー。真上からの動画があると確実

## 4b. 方針変更（2026-10-16）：滑らかなダイヤル＝ポテンショメータ＋歯車方式で行く

PEC11D（クリック式）は**保留（購入しない）**。理由：滑らかさ・回しきりの止め・電源投入時に角度が分かること・1°未満の細かさ・マイコンのピン不足の解消を優先。

### 構造
- 同軸の軸：入れ子になる真鍮パイプ（外側＝外径6mm、内側＝外径5mmのパイプか丸棒。K&S のメートル系真鍮パイプは肉厚0.45mmで入れ子になる設計）。外側に大ダイヤル（前屈/後屈）、内側に小ダイヤル（左右屈）
- 各軸に3Dプリントの歯車 → ハンドル内に横並びの**クリックなしポテンショメータ（B10KΩ＝直線、約300°で止め付き）2個**を回す。同軸の問題は歯車で横にずらして解決
- 軸受けは当面プリントのブッシュ。Oリングで回転に適度な重さ（手を離しても止まる）
- 歯車比は、大学で測る実物ダイヤルの回転角で決める（実物の全回転角 → ポテンショメータの約300°の内側に収める）
- M5StickC Plus2 のピン：ポテンショメータは ADC1 の G32・G33（Grove 端子）、ボタンは G26・G36 など。ゼロ点合わせは不要（絶対角）。両端に回しきったときの値を一度記録するキャリブレーションだけ

### 持ち方（2026-10-21 ユーザー提示、こちらが正。先に見せた成書の図は古い情報として破棄）
- 左手で操作部、右手でシャフトの両手操作が標準。観察中は持ち替えない
- 左手：**親指＝大ダイヤル（前屈/後屈）**、**人差し指・中指＝小ダイヤル（左右屈）**、**薬指・小指＝グリップを握って支える**、空いた指でロックレバー・オムニプレーンのボタン等
- 右手：口元近くでシャフトを持ち、**挿入・引き抜き**と**シャフトをひねる主軸回転**
- **実際の臨床（ユーザーの経験）**：指の担当は固定ではなく、大ダイヤル・小ダイヤル・オムニボタンを**親指・人差し指・中指のうち空いている指で**操作している。薬指・小指は握って支える
- 設計への反映：
  - **最重要：大ダイヤル・小ダイヤル・オムニボタンの3つすべてが、握ったまま親指・人差し指・中指のどれからも届く範囲にまとまっていること**（指の担当を決め打ちしない）
  - グリップは薬指・小指で支えられる太さ・長さ。持ち替え不要な配置
  - 大ダイヤルは親指が自然に掛かる位置、小ダイヤルは人差し指・中指が届く位置（実機は同軸で小が手前）
  - 主軸回転は右手でシャフトをひねる → ハンドルも一緒に回るので、ハンドル内 IMU で測る方針は変わらない
  - 挿入深度も右手がシャフトで行う → 模型にもシャフト（チューブ）を付ける価値が高い。深度センサーを足すときはシャフト側（糸巻き式など）
- **口とシャフトはコントローラー完成後に作る**（順番：試作ブロック → ハンドル本体 → シミュレータ連動 → 録画 → 口とシャフト）。そのための今からの準備：
  - ハンドル本体の先端側に、シャフト（チューブ）を差し込む穴を最初から設ける（大きめにして、チューブ決定後に変換部品で合わせる）
  - M5StickC Plus2 の ADC1 ピン3本（G32・G33・G36）のうち、G32・G33 をダイヤル2つ、**G36 を挿入深度用に予約**
  - 口の部品（シャフトが通る筒、机に固定、深度センサーをここに付ける）は別部品なのでいつでも作れる

### 挿入深度・主軸回転（あとで考える）
- 挿入深度は当面センサーなし（シミュレータのスライダー／キー）。後で足すなら、予備のボリュームに糸巻きを付けてシャフトに糸を結ぶ方式が最も手軽。ほかに距離センサー
- 主軸回転は M5StickC 内蔵 IMU（MPU6886、地磁気なし）のジャイロ頼み → ドリフトする。ボタンでゼロ点合わせ、気になれば BNO085 を追加
