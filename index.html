📱 スマホで操作（連動モード）

スマホのカメラで QR コードを読み取ると、スマホがプローブの操作部になります。
いまこの画面を localhost で開いているため、スマホからはこの URL に届きません。
PC の IP アドレス（例 http://192.168.x.x:8000/）で開き直してから、もう一度「📱 スマホで操作」を押してください。
・サーバーは python -m http.server 8000 --bind 0.0.0.0 で起動
・IP の調べ方：コマンドプロンプトで ipconfig を実行し、Wi-Fi の「IPv4 アドレス」を見る
・スマホと PC は同じ Wi-Fi につなぐ（Windows のファイアウォールで python の通信を許可）
